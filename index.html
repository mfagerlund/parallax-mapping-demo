Why the outline breaks

Tangent-space POM marches a flat height field, so it can never move the polygon's edge — the tower stays a clean circle.

SilPOM marches the real ray against the real cylinder in object space. Rays grazing the limb pass through the joints between stones, exit without hitting anything, and discard — carving the outline ragged.

CryEngine ships this as Silhouette POM and describes it as "a mix between POM and tessellation… affects the silhouette as it would with a tessellated object, without actually being tessellated."

It is not equivalent to tessellation, though. Real displacement makes geometry: it shadows correctly, writes correct depth, and survives every pass. This fakes the outline with discard and never writes gl_FragDepth, so the depth buffer keeps the undisplaced hull's depth — silently wrong rather than merely absent. Most engines take the geometry path — see the cost notes in the README.

Screen-space displacement

Mode 6 is the odd one out: it is not a relief shader. The hull is rasterized into a G-buffer, then a grid of triangles one cell per screen pixel is drawn, each node pushed along the normal by the height map.

So it really is displaced geometry — it just takes its tessellation density from the framebuffer instead of the mesh. Hence "infinite detail without the memory": there is no subdivided mesh to store, and cost is a function of resolution alone. Turn on the heatmap and it reads flat, because every pixel does exactly one displacement no matter what the height map says.

It also writes correct depth, for free, which SilPOM does not — the rasterizer wrote it. That single difference removes most of the objections listed above.

What it cannot do is invent surface it never saw. The grid is a height field over the camera's view, single-layered, so where displacement should tear the surface open it stretches instead. Push Depth up and watch the smearing along the limb. Nodes at the viewport border have no neighbours, which is the screen-edge artifact.

And the vertices move without telling anyone downstream. A temporal upscaler reprojects them using motion vectors belonging to the undisplaced surface, which is the shimmer Crimson Desert shipped with and patched later. This demo has no TAA, so it does not show that one.

SSD screen grid sets the cell size in device pixels — the tessellation knob. At 1 px the outline is exact and the cost is millions of triangles; the HUD reports what was actually drawn.
